# vvkit Pitch-Ready Demo Suite

This directory contains the official "Pitch-Ready" interactive demonstration of `vvkit`. Instead of showing a dry internal API test, this demo simulates exactly how a client or computational scientist would integrate their massive external numerical solvers with the `vvkit` verification harness.

## What it Demonstrates

1. **External Orchestration (`CommandAdapter`)**: Shows how `vvkit` executes external binaries in isolated workdirs using Jinja2 configuration templates, just as it would for a C++ CFD solver. We use `mock_solver.py` to simulate this gracefully across all platforms.
2. **Method of Manufactured Solutions (MMS)**: Demonstrates the symbolic mathematics engine reading a declarative YAML file and emitting a real C++ source term file (`mms_source.c`) required for convergence testing.
3. **Automated Convergence Pipelines**: Shows how `vv run` orchestrates the grid refinement matrix (`n=[32, 64, 128, 256]`), reads the NumPy arrays generated by the solver, computes analytical L2 norms via SymPy, and extracts the Least-Squares order of accuracy and GCI.
4. **CI-Ready Reporting**: Exhibits the generation of HTML and JUnit XML reports for deployment into continuous integration pipelines.

## Running the Pitch

The entire pitch is automated using an interactive terminal script powered by `rich`. 

To launch the pitch, simply execute:

```bash
uv run python run_pitch.py
```

The script will guide you step-by-step through:
1. Reviewing the declarative YAML contract.
2. Generating the MMS source terms.
3. Executing the solver grid refinement sweep.
4. Generating and reviewing the reports.

## Exploring the Artifacts

After running the pitch, explore the `reports/` directory to view the generated HTML plots and regression baselines.
